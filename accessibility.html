Accessibility Statement

How the Moquim Foundation website supports accessibility, and how to report a problem.

The Moquim Foundation wants this website to be usable by everyone, including people using screen readers, keyboard navigation or magnification.

What we have done

This site is built to target WCAG 2.1 Level AA. Every image carries descriptive alternative text. Colour combinations have been checked to meet the AA contrast ratio. Headings follow a logical order without skipped levels.

The site can be navigated entirely by keyboard, with a visible focus indicator on every interactive element. Skip links at the top of each page jump straight to the main content or the footer.

Where a visitor has asked their system to reduce motion, the hero carousel stops advancing automatically and animations are disabled.

Known limitations

The site is currently in English only. An Odia translation is planned. Video content does not yet carry captions or a transcript; we intend to add both.

Reporting a problem

If you have difficulty using any part of this site, please tell us. Write to moquimfoundation.org@gmail.com or call +91 99370 81575 and we will help you directly and fix the problem.

Last updated 2026-07-31. This wording must be reviewed by a lawyer before the site goes live.
